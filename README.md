# SFX Preview Site Update

Place these files in the root of your GitHub Pages SFX library:

- index.html
- .nojekyll
- manifest.csv
- category folders containing the WAV files

Features in this version:
- Persistent favorites using localStorage
- Favorites-only filter
- Per-sound WAV download button
- Downloads preserve the original WAV filename
- Search and category filtering
- Play/pause, seek, stop-all, and master volume
- Responsive layout

The `.nojekyll` file is intentionally empty.
